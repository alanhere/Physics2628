✏️ Teacher Lesson Editor

Fill in your lesson, attach resources and publish everything to GitHub in one click.

Important: The editor is publicly viewable, but publishing requires your GitHub authorisation. For security, use a fine-grained token with Contents: Read and write permission for this repository only. Your token stays in browser memory and is never saved. For best security, open this editor locally on your own computer, not on a shared device. Do not enter student personal data.

🔐 GitHub publishing

Grant access only to this repository, with Repository permissions → Contents: Read and write. Never put this token in a file or commit it. It is not stored by this editor.

Publishing makes one GitHub commit containing the lesson and attachments. GitHub Pages then deploys the site (usually after a short delay). The editor fetches the latest lesson data directly from GitHub before every publication, merges your lesson safely, and checks for concurrent updates.
